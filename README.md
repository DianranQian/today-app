# What to Do 🎲

> 选择困难终结者。一个 App 装下五个「今天」：吃什么、去哪、穿什么、联系谁、待办。

## 功能

| 子应用 | 说明 |
|---|---|
| 🍜 **今天吃什么** | 随机推荐菜谱（老虎机滚动动画），400+ 家常菜 + 75 种饮品，按季节优先、避免近期重复，支持忌口设置、自定义/文件导入菜谱、AI 推荐 |
| 📍 **今天去哪** | 随机推荐去处（65 个内置：吃饭/逛街/公园/文化/运动/夜生活），可按类型、预算筛选，支持高德附近搜索 + AI 推荐 |
| 👕 **今天穿什么** | 按性别（男/女）、人群（学生/上班族/长辈/儿童）、当前季节、温度区间随机搭配（62 套内置） |
| 📞 **今天联系谁** | 记录亲友联系频率，逾期优先提醒，「已联系打卡」自动更新下次提醒 |
| 📋 **今天待办** | 按日期管理的每日待办清单，勾选/清空已完成 |

## 特色

- 🎰 **老虎机动画**：随机结果以滚轮滚动 + 减速定格呈现，点击结果可换一换
- 📂 **多方案管理**：每个子应用可建多套方案（吃什么=菜单、去哪=地点集、穿什么=衣柜、联系谁=电话簿），随时切换；「参与随机的方案」多选可让多套方案一起进随机池
- 🌐 **中英双语**：设置内一键切换中文 / English，全部 UI 即时生效
- 🎨 **自定义主题**：五个子应用各自独立选色（8 色板）
- 🍃 **应季优先**：自动读取当前季节，当季内容优先推荐
- 🤖 **AI 推荐**：接入 DeepSeek，基于附近高德 POI 智能推荐餐厅/去处
- 📁 **数据自由**：所有数据本地存储，支持增删改查、JSON 文件导入、**全量 ZIP 备份导出/导入（含照片）**
- 🖼️ **图片支持**：各子应用均可为条目添加照片（相册/拍照），有图优先展示
- 🔒 **隐私友好**：不收集任何数据，不读系统通讯录，联系人手动录入且仅存本机
- 💰 **开源免费**：全靠自愿打赏（App 内「赛博乞讨」）

## 构建

```bash
flutter pub get
flutter run          # 调试运行
flutter build apk --release   # 打包
```

- Flutter 3.24+ / Dart 3.5+
- Android 6.0+（minSdk 23），compileSdk 35
- 注意：项目路径请使用纯英文（中文路径会导致 impellerc 构建失败）

## 技术架构

```
lib/
├── main.dart          # 主框架：子应用入口页 + 通用设置入口
├── core/              # 共享层：主题工厂、全局设置、方案管理、i18n 字典、
│                      #   ZIP 备份、季节、图片工具、老虎机组件、打赏
├── pages/             # 通用设置页（主题色/语言/API Key/备份）
└── apps/
    ├── eat/           # 今天吃什么（含 400+ 菜谱数据）
    ├── go/            # 今天去哪
    ├── wear/          # 今天穿什么
    ├── contact/       # 今天联系谁
    └── todo/          # 今天待办
```

五个子应用相互独立（各自的数据模型与存储键），可随时拆分为独立 App。
